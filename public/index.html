Desktop · SyncPlayU

SyncPlayU is the Night build of Syncplay. It automatically rejoins your room after a network drop.

Download SyncPlayU for macOS · Latest desktop release and source

Apple Silicon · macOS Sonoma (14) or later. This build is ad-hoc signed and unnotarized. If macOS asks for approval, follow Apple’s first-launch instructions.

Install on macOS with Homebrew

If you installed the original Syncplay cask, quit Syncplay and remove that cask first. This keeps your settings.

brew uninstall --cask syncplay

Install SyncPlayU:

brew install --cask NightMachinery/tap/syncplayu

Already using SyncPlayU? Run brew update, then brew upgrade --cask syncplayu. About shows both the upstream and Night versions.

Share mpv playback speed

With SyncPlayU Night 3 or later, use mpv’s normal speed controls to set the room rate from 0.25× to 4×. Press Backspace to reset to 1×. In a managed room, a room operator controls the speed.

The server and every viewer in the room must support shared speed. If a viewer joins with an older client or an unsupported player, the room returns to 1×. Everyone can still pause, seek, and watch together.

Android · SyncPlayU

Download SyncPlayU for Android · Latest Android release and source

Android 8.0 or later. The APK installs alongside upstream Synkplay. Choose ExoPlayer or mpv, open a video, then select Control panel → Room playback speed to share playback speed with other viewers.
